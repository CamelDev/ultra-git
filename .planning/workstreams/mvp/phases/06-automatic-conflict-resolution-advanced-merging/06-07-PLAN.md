Staged-discard must be one rollback-capable transaction. Remove unconditional context-free and whitespace/context retry behavior from this path. Register successful transactions with the existing undo model using opaque before/after safety handles; invalidate Undo/Redo on external identity mismatch and return a stable expiry reason.</action>
